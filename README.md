# Rommariel Joyas — Catálogo Oficial & Carrito WhatsApp

Plataforma de catálogo interactivo y pedidos vía WhatsApp para **Rommariel Joyas**, con más de 50 años de tradición en Paraguay.

---

## 💎 Características Principales

- **Catálogo Interactivo**: Filtrado por categorías (Aros Tapa Florales, Corona & Gemas, Trepadores, Argollas de Oro, Colgantes & Dijes) y acabados.
- **Hero Cinematográfico**: Video de alta joyería en bucle continuo con gradiente marrón chocolate orfebre para óptima legibilidad.
- **Micro-Interacciones de Lujo**:
  - Efecto *Shimmer* (haz de luz) en fotos de producto.
  - Zoom interactivo en alta resolución.
  - Insignias de *Más Vendidos* con destello estelar animado.
- **Carrito & Cierre por WhatsApp**: Genera automáticamente el mensaje estructurado con código SKU, descripción, fotos, montos en Guaraníes y datos de transferencia bancaria de UENO Bank.
- **Flotante Concierge**: Botón directo de atención personalizada por WhatsApp en la esquina inferior.
- **Guía de Medidas de Anillos & Modal Institucional**: Información histórica, política de cambios (5 días hábiles) y condiciones mayoristas.

---

## 🛠️ Stack Tecnológico

- **Frontend**: React 19, TypeScript
- **Bundler & Build Tool**: Vite 6
- **Estilos**: Tailwind CSS 4, Google Fonts (Playfair Display, Cinzel, Inter)
- **Iconos**: Lucide React
- **Despliegue**: Optimizado para Vercel (SPA)

---

## 🚀 Instalación y Desarrollo Local

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Ejecutar servidor de desarrollo**:
   ```bash
   npm run dev
   ```

3. **Compilar para producción**:
   ```bash
   npm run build
   ```

---

## 🌐 Despliegue en Vercel

1. Conectar este repositorio (`Morochief/rommariel-joyas`) en [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. El archivo `vercel.json` incluido gestiona automáticamente los rewrites para Single Page Application (SPA).
